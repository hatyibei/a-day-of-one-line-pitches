One sentence to convince a friend who has never coded to let an AI agent build their first app idea on make.fun, written for the “A Day of One-Line Pitches” bounty.

## Run it

```sh
python3 main.py
```

## The entry

> You've kept that app idea in your notes for two years — tonight you can just describe it in plain words, watch an agent build it before dinner, and keep every line of the code, without writing any of it yourself.

## Files

- `entry.txt` — the entry itself, byte for byte what the program writes out.
- `main.py` — copies `entry.txt` into the output directory the harness sets (`$MAKEFUN_OUTPUT_DIR`, or `/output` when unset).
